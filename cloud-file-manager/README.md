# 智云盘 - 云端文件管理系统

一套功能完整的云端文件管理前端系统，对标百度网盘基础管理能力。

## 功能特性

### 📁 文件管理
- **多类型文件支持**：图片、文档、视频、音频、压缩包、代码文件等所有主流格式
- **文件操作**：新建文件夹、重命名、移动、复制、删除、批量操作
- **拖拽操作**：支持拖拽文件到对应文件夹进行移动
- **压缩/解压**：支持文件批量压缩为ZIP、压缩包解压
- **回收站**：删除的文件自动进入回收站，支持恢复和永久删除，30天后自动清理

### ☁️ 上传功能
- **多文件批量上传**：支持同时选择多个文件上传
- **文件夹上传**：支持整个文件夹目录结构上传
- **大文件分片上传**：5MB分片，支持超大文件上传
- **断点续传**：刷新页面后可继续未完成的上传
- **上传控制**：支持暂停、继续、取消单个/全部任务
- **实时进度**：显示文件名、大小、上传进度、上传速度、剩余时间
- **自动重试**：上传失败自动重试3次，重试失败标注失败原因

### 🔍 检索功能
- **关键词搜索**：实时模糊搜索文件名
- **类型筛选**：按图片、文档、视频、音频、压缩包、代码等类型筛选
- **大小筛选**：小于1MB、1-10MB、10-100MB、100MB-1GB、大于1GB
- **时间筛选**：今天、本周、本月、今年、全部时间
- **多维度排序**：按名称、大小、修改时间、类型升降序排序

### 👁️ 文件预览
- **图片预览**：支持缩放、旋转、鼠标滚轮缩放
- **文档预览**：PDF、Word、Excel、PPT占位预览（需后端支持）
- **视频预览**：HTML5播放器，支持播放/暂停、进度调节
- **音频预览**：HTML5播放器
- **代码预览**：代码高亮显示

### 🔗 分享功能
- **私密分享**：生成带提取密码的分享链接
- **公开分享**：无需密码即可访问
- **有效期设置**：1天、7天、30天、永久有效
- **访问限制**：可设置最大访问次数
- **下载控制**：可设置是否允许下载
- **分享管理**：展示所有已分享文件、分享状态、访问记录

### 📊 存储管理
- **容量统计**：首页可视化展示已用容量、剩余容量、容量占比
- **分类统计**：各类型文件数量统计
- **最近文件**：快速访问最近修改的文件

### 🔐 权限管控
- **未登录用户**：仅可浏览文件，禁止上传、下载、分享
- **普通用户**：完整的文件管理权限
- **管理员**：可查看所有用户文件、清理违规文件、系统设置

### ⌨️ 快捷键支持
- `Ctrl + A` - 全选
- `Ctrl + F` - 搜索
- `Ctrl + U` - 上传文件
- `Ctrl + J` - 打开上传控制台
- `Ctrl + S` - 切换视图模式
- `Ctrl + C` / `Ctrl + X` / `Ctrl + V` - 复制/剪切/粘贴
- `Ctrl + Shift + N` - 新建文件夹
- `Delete` - 删除文件
- `F2` - 重命名
- `Enter` - 打开/预览
- `F5` - 刷新
- `Esc` - 取消选择
- `Alt + ←` - 返回上一级

### 📱 多端适配
- **电脑端**：完整操作界面，表格/网格双视图
- **移动端**：简化操作布局，触控优化

## 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **Pinia** - Vue 状态管理
- **Vue Router** - Vue 官方路由
- **Element Plus** - Vue 3 组件库
- **ECharts** - 数据可视化图表库
- **Sass** - CSS 预处理器
- **@vueuse/core** - Vue 组合式工具集

## 核心实现说明

### 分片上传实现
- 每个文件按5MB分片
- 使用 FileReader 读取分片内容
- 支持暂停和继续（已上传分片不会重复上传）
- 失败自动重试3次
- 实时计算上传速度和剩余时间

### 权限控制
- 路由级权限：通过路由守卫判断登录状态和角色
- 功能级权限：通过 `hasPermission` 方法判断操作权限
- 管理员权限：独立的管理后台页面

### 数据持久化
- 使用 localStorage 存储用户信息、文件数据、上传任务
- 页面刷新后数据不丢失
- 回收站30天自动清理机制
